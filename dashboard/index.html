Architectural Design: Multi-Stage Blending Pipeline

Rather than predicting winners using simple historical averages, this system builds a multi-stage regressor and classifier pipeline. Position regression is combined with raw win probabilities, dynamically penalized by mechanical and weather-based DNF risks to call the final order.

Feature Engineering: Domain-Specific Extraction

A model is only as good as its features. This pipeline extracts dynamic in-season form coefficients (constructor point momentum), historical track affinity indicators (14 years of driver/constructor finishes per circuit), live weather probability metrics, and FP2/FP1 practice lap pacing to capture real-time driver performance.

Validation Strategy: Leakage Prevention & Validation

Standard random cross-validation splits fail in F1 telemetry: lap times and constructor conditions from a single race weekend will leak from the validation fold into the training folds, inflating model accuracy. We use **GroupKFold (grouped by race round)** to test models exclusively on complete, unseen weekends, assuring valid real-world generalization.

Data Orchestration: API Reliability & Orchestration

Our data pipeline orchestrates live session APIs (FastF1, OpenF1, Jolpica) with resilient request handling and exponential backoff retry mechanisms. By mapping hardware failures, tire degradation rates, and weather conditions, we build a highly reliable technical predictive backend.
